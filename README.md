# Bilt 2.0 Points Calculator

A single-page calculator for comparing the two Bilt Card 2.0 reward structures:

- **Option 1 — Housing Rewards:** Earn tiered Bilt Points directly on rent (1×–3× depending on monthly non-rent spend)
- **Option 2 — Flexible Bilt Cash:** Earn 4% Bilt Cash on non-rent spend, then convert it to unlock 1× points on rent — with any leftover cash usable toward the Point Accelerator bonus

Supports all three Bilt cards: **Blue**, **Obsidian**, and **Palladium**.

## Features

- Card selector with per-card earn rates and annual fee context
- Separate rent and non-rent spend inputs (or a single spend field for Blue/Palladium)
- Obsidian bonus category toggle (dining vs. travel)
- Spend tier indicator with live tier tracking (Obsidian)
- Point Accelerator calculation — amortizes $200 BC → 5,000 bonus pts across activations
- Side-by-side results with a winner badge and recommendation
- Full assumptions table (rates, conversions, PA terms) based on official March 2026 terms

## Usage

Open `index.html` directly in any modern browser — no build step or server required.

## Data Source

Based on official Bilt Rewards 2.0 terms (March 2026).
